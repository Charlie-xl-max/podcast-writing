# 延续作者已有风格

当用户提供过往播客文稿、录音转写、节目链接中的文字材料或明确的风格说明，希望新内容延续个人表达时，先从样本中提炼稳定、可观察的写作选择，再用于当前任务。样本提供的是表达参考，不代表本期事实，也不意味着要机械复制旧稿。

## 选择和判断样本

- 优先使用用户明确指出的代表作，或与当前节目形态、主持人、用途最接近的材料。
- 多篇样本通常比单篇更能反映稳定习惯。只有一篇时，把结论当作暂定观察，不推断成固定人格或完整作者画像。
- 录音转写含有识别错误、剪辑痕迹或大量口头赘词时，不要把这些噪音当成作者风格。优先观察稳定的用词、句子节奏、解释习惯、幽默方式、观点推进和与听众的距离。
- 多位主持人的材料要分别识别声音特征。多人合写稿不能自动归结为某一位作者的个人习惯。
- 主题、平台和节目形态会改变表达。区分作者稳定习惯与某一期题材、嘉宾或平台要求造成的变化。
- 如果样本互相冲突，优先参考用户标为当前或最接近本期需求的材料；仍无法判断时，简短询问想沿用哪一种，或说明采用的暂定方向。

## 提炼为可执行的风格提示

只记录对本次写作有帮助的少数特征，例如：

- 口语浓度、句子长短和停顿节奏
- 常用的开场方式、转场方式和收尾方式
- 如何解释背景、举例、提出判断或表达不确定
- 幽默、情绪和个人经验的使用程度
- 主持人与听众之间的距离，以及多人之间的互动节奏
- 明确不希望出现的写法

把观察写成可执行的指引，例如“先从一个具体场景进入，再解释背景”“判断前先交代依据”“可以偶尔自嘲，但不连续堆梗”。避免空泛标签，如“很有网感”“很松弛”“很有深度”，除非同时说明它在语言上的具体表现。

## 应用风格而不照抄

- 延续节奏、语气、解释方式和互动习惯，不照搬旧稿中的句子、段子、故事、观点或事实。
- 新稿的事实、立场和经历只来自本期材料或已核实来源。不能因为作者旧稿讲过某种经历，就默认本期也可以用。
- 风格与清晰、事实准确或节目用途冲突时，优先保证内容准确、听众听得懂，再尽量保留作者的表达习惯。
- 逐字稿可以保留样本中真实且有辨识度的口语节奏，但不要为了模仿而塞入固定口头禅、错句或样本里偶然出现的语气词。
- 如果用户只说“按我的风格写”，但当前对话和可用材料里没有样本，不要声称已经了解其风格。可以先按本 skill 的默认写法起草，并邀请用户提供一两篇代表作或一段转写；材料足够重要时再先询问。

## 汇报方式

只有在有助于用户判断时，才用一两句话说明采用了哪些风格特征、参考了哪些样本，或哪些观察仍不确定。用户只要成稿时，不附冗长的风格分析报告。除非用户明确要求生成可复用的风格说明，否则不自动创建作者画像或长期个人规则库。
